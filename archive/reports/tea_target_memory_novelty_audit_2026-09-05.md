# 茶芽初扫地图、位置记忆与末端视觉接管：重复审查及实验收敛方案

检索日期：2026-09-05。对象：树上茶芽；硬件边界为开发板、720p 双目深度相机及可搭建的电动相机平台。目标是支持 SCI JCR Q1–Q3 选题判断，本报告不把会议或预印本当作 SCI 期刊，也不据技术方案预测录用概率。

**判断：工程上可以实现；系统框架的重复风险较高。最值得保留的是“旧位置在多大误差和扰动下仍足以找回正确目标，以及何时必须刷新”的具体问题。**

本次进行了 25 组定向检索，纳入 11 篇直接或方法近邻。检索跨茶叶、玫瑰修剪、柑橘跟踪、葡萄选择性采摘、果实三维地图、植物形变配准和视觉控制。属于公开网络广度审查，不是 Web of Science/Scopus 全库系统综述；未检出完全一致的流程不构成“无人研究”或“首次”的证明。部分出版方全文受限，以下明确区分核查深度。

**对用户方案的准确理解。**

同一末端相机先从多个实际位置观察局部作业区域，积累茶芽身份、叶数/等级证据和三维位置。作业中只精细更新当前目标；离开视野的目标保留较粗且随时间变旧的位置。候选充足时，按地图前往一个适合重新观察的位置，识别同一茶芽后进入近距视觉控制；候选不足时补扫，结束时检查残留。

这里有三个不同问题：是否识别为同一根芽、该芽符合何种采摘规格、该芽目前在哪里。它们的证据可以分别保存与更新。不能把单帧检测分数同时解释成这三项都可靠。

**初扫能减轻第二片叶被遮住的误判，但不能保证消除所有遮挡。**

扫描覆盖一片区域，只说明相机访问了预设位置。要可靠区分一芽一叶和一芽二叶，还需要看见足够的器官证据，并确认叶片属于同一根芽。有限可达视角、内层叶片、叶与茎连接处遮挡、重复纹理、风动以及深度缺失都可能使初扫后仍有未知目标。仅有正面和侧面照片，也不能把“没有看见第二叶”直接推成“确实没有第二叶”。

可将初扫结果分为：
- 身份与等级证据足够：进入可用候选池；
- 有目标和粗位置，但等级证据不完整：保留为待确认；
- 从未被看见：没有对象记录，仅保留相应区域的观察覆盖信息。

因此，“只剩采掉前方芽才会露出的后方芽”应作为需要验证的实验假设。判定办法是将初扫结果与独立人工解遮挡核验的真值比较，统计仍隐藏的结构和误判来源。R08 的数据标注明确存在严重遮挡叶片不标注的边界；这类分级论文的指标不能替代本问题的验证。

在短时间作业中，同一茶芽的生物学叶数通常比空间姿态变化慢，可以复用先前已确认的等级证据；但前提是重新确认身份，且没有局部采走/折断器官等改变等级的事件。论文还需明确标签表示“在树上的芽叶结构”还是“计划采下的产品规格”，两者不能混用。

**“维护三维位置”有两种含义。**

保存最后一次估计的位置、维护误差范围、在重新观测后校正：可以实现。持续知道不可见茶芽的真实当前位置：仅靠存储不能实现。预测模型可给出条件估计，但缺少新观测时无法排除风、枝条接触或采摘回弹造成的变化。

建议每个目标至少保存：

| 字段 | 用途 |
| --- | --- |
| 目标 ID、局部外观/邻域关系 | 返回时判断是否同一芽 |
| 最近位置估计及误差区域 | 决定重观测位置和搜索范围 |
| 位置更新时间、观测相机位姿 | 判断记录是否过旧，支持坐标变换 |
| 等级状态及支持该结论的关键视图 | 区分已确认和待确认；返回时无需无条件重做完整分级 |
| 待确认、可重访、已采、疑似失效等状态 | 防止重复处理和错误沿用 |
| 同枝/邻近关系及关系置信度（可选） | 在采摘扰动后选择性降低相关目标的位置可信度 |

这可以是稀疏对象表，不必先做整株高精度稠密重建。存磁盘便于恢复和复现实验；运行时活动目标通常放在内存即可。减少存储小数位不会减少真实位置误差，不能把“数值精度降低”包装成“允许物理位置模糊”的贡献。

**统一坐标系是可实现性的必要条件。**

双目输出首先是相机坐标系中的三维量。要将不同扫描位置的结果融合并再次前往该目标，需要知道每次相机相对平台基座的位姿，例如：

\[
p_{\mathrm{base}} = T_{\mathrm{base}\leftarrow\mathrm{camera}}(q_t)\,p_{\mathrm{camera}}.
\]

在固定基座、可回零的平台上，可以通过执行轴位置、运动学和相机安装标定建立此关系，不必一开始实现完整移动 SLAM。平台移动、重新安装或重启后坐标参考丢失时，需要重新对齐地图。

初扫要利用遮挡变化，相机光心应有实际平移。仅在原地转动云台主要改变朝向，不能有效绕开同一遮挡物。720p 本身不能决定能否工作：还需测定镜头焦距、双目重叠视野、最小有效深度距离、茶梢像素尺寸、平台回差和停止后的成像稳定性。

**视野外位置可以粗到什么程度？**

物理上的粗位置应服务于“重新找到正确目标”，不需要提前达到最终采摘点精度。

定义误差区域为目标可能所在的范围；定义某个相机位姿的“可重新观测区域”为相机能够清楚观察且有效处理的工作空间。前往目标附近时，应让目标误差范围尽量落入这个区域，并控制相似邻芽造成的身份混淆。误差区域落入视野只是几何条件，遮挡、成像质量和关联错误仍可能让重获失败。

可以将以下条件作为拟研究的决策目标，而非现成保证：

\[
P(\text{重新找到正确目标}\mid\text{旧地图、拟选相机位姿、扰动历史})\ge 1-\alpha .
\]

概率必须通过独立试验校准。简单设置一个高阈值或给出高检测分数，并不证明满足该条件。更保守的实现可以使用经验证的误差包络和分组成功率，不必预设所有误差都服从高斯分布。

靠得更近时目标像素增多，但物理视野也变窄；旧位置较不确定时，先在稍远处重获，再进入近距视角可能更有效。具体距离由相机实测决定。按旧坐标移动应以到达可重观测位姿为目的，并满足路径可通行；目标地图不能自动替代障碍物信息。

这也能连接原来的 ROI 工作：将目标误差区域投影到当前图像，确定一个覆盖概率可校准的 ROI；重新找到目标后再收缩。ROI 成本要用实际开发板上的推理时延测量。裁剪不能凭空增加原始成像细节，只可能减少整图缩放造成的细节损失及无关计算。

**建议优先研究一个主问题，再选一个从属问题。**

| 问题 | 可证伪假设 | 必须比较的简单方法 | 适合的合作者贡献 |
| --- | --- | --- | --- |
| A. 旧位置何时仍可用于重访？ | 利用失去观测时长、平台误差、干预事件预测重获可行性，可在相同可靠性要求下减少刷新 | 从不刷新、固定时间刷新、每次全扫 | 基础控制：实测回差与重访；现代控制：误差集合传播及事件触发 |
| B. 采一根后，哪些旧位置需要失效？ | 采摘导致位置变化与枝条联系有关，按动作影响选择刷新可优于固定空间半径 | 全部失效、只删已采芽、固定半径失效 | 基础机械：搭建可重复扰动；现代控制：局部耦合扰动模型 |
| C. 应在何处让末端视觉重新获取目标？ | 依据目标误差范围及有效视野选择观察位姿，可降低找不到或找错芽的概率 | 固定距离、固定偏移、预设小扫描 | 基础控制：平台轨迹；现代控制：受约束的切换条件 |
| D. 已确认的等级证据能否复用？ | 先确认同一目标、再复用既有器官证据，可减少重复分级和返回时的遮挡误判 | 每次独立分级、完全沿用旧等级 | 视觉算法主导，机械保证重复视角与可核验移动 |
| E. 必须一开始扫完吗？ | 部分场景中先建足够候选、边作业边补扫可缩短整区用时；也可能全扫更好 | 完整初扫、固定预算初扫 | 自动化调度与系统试验 |

优先建议 A 为主、B 或 C 为辅。D 可作为应用约束和失败分析，不建议一次同时做完整新分级网络、新三维重建、新跟踪、新控制器和新末端。

B 的风险也需正视：看不清枝条连接时，不能强行给每个芽分配准确拓扑。可先从可靠的局部关系或保守的扰动范围开始；若简单固定半径已经同样有效，就不应再声称复杂图模型有必要。

**最小实验方案。所有条目均为研究建议，不是已完成结果。**

| 实验 | 操作与变量 | 主要指标及真值 | 能排除什么疑问 |
| --- | --- | --- | --- |
| 1. 初扫能否支持等级判断 | 固定茶树小区域；比较单视角、预设多视角；将第二叶/叶茎连接遮挡单独分层 | 等级错误率、待确认比例、初扫覆盖率、扫描用时；人工解遮挡核验真实器官归属 | 区分“扫过区域”和“等级证据足够” |
| 2. 离开视野后返回 | 同一芽离开视野后，从不同位置返回；改变间隔、平台运动次数、风动及目标密度 | 正确 ID 重获率、错误 ID 率、找不到比例、重获用时；跨视角人工核验身份 | 检验粗位置是否足以支持实际行动 |
| 3. 采摘后地图有效性 | 初扫后移除某一芽，记录同枝及邻近目标；比较无干预、局部轻触、真实移除 | 各目标重访误差/重获结果、受影响范围、刷新开销 | 检验只删已采芽是否足够，是否需要选择性失效 |
| 4. 视觉接管与 ROI | 比较固定接管距离/固定 ROI 和误差驱动策略；加入平台偏差及处理时延 | 正确重获率、错误关联、局部对准误差、实际推理时延与总耗时 | 检验新策略是否超越调阈值 |
| 5. 区域作业 | 在独立茶树区域完成初扫、采摘/对准、补扫、结束核验 | 单位时间合格产出、全流程时间、残留分解；有真实机构时加损伤率 | 检验局部视觉收益是否变成系统收益 |

前期可以人工移除芽来产生可复现扰动，用于研究地图更新和相机重新获取。此时只能报告感知/对准结果，不能报告自动采摘成功率或末端低损伤能力。灌木可以用于平台回差、运动模糊、目标离开后返回等调试；茶芽等级、细茎深度和器官归属结论必须在茶树验证。

单台实验相机能够支持人工核验身份和重获结果。若要声称毫米级绝对三维误差，应另有精度更高的参考或已知位移工装；不能把同一相机再次测到的位置直接当成无误差真值。

训练、校准和测试应按植株/区域/日期分开。相邻视频帧不能冒充独立试验。多个策略在可重复的非破坏任务中可配对比较；真实采摘会改变场景，应采用随机分配的独立区域或匹配区域，并报告不确定性。样本规模先由预实验的错误率及想分辨的差异决定，不以几条成功视频替代统计证据。

**区域指标要与用户的阶段划分保持一致。**

候选充足阶段主要关心可持续提供正确目标以及处理效率，可以暂缓精确维护其他目标。候选不足时，重观测价值上升；结束时仍须按预先定义的目标集合核验残留。

建议报告：
- 正确目标重获率 = 成功找回原指定目标的重访次数 / 全部重访尝试；
- 错误身份接管率 = 将其他芽作为指定芽接管的次数 / 全部重访尝试；
- 各失败结果分别为找不到、身份不明确、等级未确认和执行失败；
- 残留分为从未检出、已检出但拒绝、不可达及执行失败；
- 全流程时间包含初扫、平台移动、计算等待、重定位、采摘、补扫和结束检查；
- 固定可靠性要求下比较时间，或给出可靠性与时间的完整权衡曲线。

若只检测/对准而没有真实采摘，效率指标应叫合格目标确认/对准次数，不能改称茶芽产量。损伤指标只有开展真实采摘并定义采下组织与留树组织的评价范围后才能成立。

**合作者的两个转向。**

偏机械设计与基础控制：优先做固定基座的平移相机平台、回零与重复定位、安装刚度、停止成像和短距离对准。方法侧重点是实测旧位置失效规律及可靠的选择性重扫；无需为了形式而堆叠复杂控制器。

偏现代控制理论：可以把目标位置误差传播、视觉观测中断、重新获取条件和控制切换联系起来。需要明确模型假设、允许扰动、时延和重获失败处理，并证明或实验证明所声称的性质。仅采用 Kalman 滤波、MPC 或切换控制名称不自动形成创新。视野约束主题见 R11。

可用暂定题目：**“面向茶芽区域采摘的三维目标记忆有效性评估与近距视觉接管”**。题目对应的论文承诺应是可验证的记忆刷新与接管收益，而非“建一张三维图”。对于 JCR Q1–Q3 目标，现有证据更支持这种窄问题、真实闭环和独立区域验证的准备路线；具体期刊分位仍应按投稿当年 JCR 学科类别另行核实。
