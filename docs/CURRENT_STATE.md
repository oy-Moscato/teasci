## 2. 用户提出并保留的工作逻辑

- 工作阶段只要存在通过准入门限的目标就可以继续作业，不必先识别每个目标或先解决最难遮挡芽。
- 候选充足、候选补充、最后查漏可有不同观察目标。单次空检测、队列为空、区域已无合格目标不是同一事件。
- 视野外只保留足以返回附近的模糊位置可以接受；只有局部接管时需要较精细的位置和等级证据。
- 返回时可以重新确认并选择另一个合格芽；只有沿用旧芽的等级证据等任务才必须确认同一身份。
- 严重实体缠绕若实际发生比例很低，不以其为主问题。普通扰动若仍落在允许的粗位置范围内，也不强行建复杂动态模型。
- 初扫多视角用于减少第二叶遮挡造成的误分级；“初扫后只剩采掉前芽才露出的后芽”仍是待实验核验的假设。
- 相机安装靠近末端，强调局部看准；粗扫后的重叠芽簇概率云可用于几何驱动观察，但框架本身已有方法近邻。

## 3. 当前候选问题（建议，未最终锁题）

在固定空间区域内，初始芽数和芽位未知，使用开发板与双目移动相机，在相同观察预算和误检约束下选择下一视点，提高独立芽梢的区域累计发现率。

优先区分三个状态：

| 状态 | 需要补充的信息 | 不能混用的指标 |
| --- | --- | --- |
| 已发现但芽簇合并或身份混淆 | 是否为多个独立芽梢、跨视角去重 | 合并/重复计数不等于分级错 |
| 已发现但叶片或叶茎连接被遮挡 | 等级判据、同梢器官归属 | 分级拒绝不等于从未发现 |
| 起初完全未发现的芽 | 未充分观察区域中的新目标 | 仅改善已有概率云不能证明减少全部漏芽 |

自然茶树上的区域主动发现是待补证的应用问题；通用 NBV、语义地图、信息增益、跟踪、主动分类已有研究。项目贡献必须体现在明确机制和可重复增量上。

## 4. 暂不作为主线的内容

- 从零开发完整采茶车、采摘灵巧手、收集系统和整机故障恢复。
- 单纯换 YOLO 骨干、加注意力、裁剪 ROI、加 EKF 或画状态机来主张首次。
- 没有数据支持就研究细粒度地图老化、所有枝条的复杂耦合形变或稀有缠绕。
- 同时宣称高分级、高定位、高覆盖、低损伤、全局最短作业时间全部优化。
- 把“连续 K 次未发现新芽”或“地图熵很低”直接解释成数学保证的零漏芽。

这些方向保留在历史候选库中，只有实际失败与收益证据才触发重新评估。
