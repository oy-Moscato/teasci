# 最小可行实验计划

状态：`pilot-v0.2` 建议协议，未执行。主线是相机反馈控制的区域发现；[行动前准备](PREPARATION.md)给出分阶段进入条件，[指标口径](METRICS.md)和[TASKS](TASKS.md)管理定义与认领。

## 先验证的假设

H1：自然茶树固定区域中，有限的固定视角扫描会留下足够常见、可由额外可达视角揭示的目标，构成有实际意义的漏检来源。

H2：在相同误检约束和观察预算下，利用当前几何/观察历史选视角，能比合理固定扫描和已有主动视觉方法发现更多不同芽梢。

H3（条件）：如果等级证据缺失是主要瓶颈，针对叶片—茎归属和第二叶可见性的观察能提高正确准入，而非仅增加检测框。

H1 不成立时，不为论文强造罕见遮挡。H2 不成立时记录负结果，优先调整问题或采用简单方法。

## 硬件与范围

拟采用固定基座、可返回已知位姿的相机运动机构、现有双目深度相机与开发板；本轮实物身份和配置尚待核对。先测已有安装与可达观察范围，再决定自由度/行程。围绕光心旋转主要改变朝向；若转轴偏离光心，云台也可能产生光心位移，不能仅凭“只有两轴”断言是否能改变遮挡。

多位姿融合需要相机到基座的标定与每次观察位姿。板子/相机型号未知，不预先宣称毫米精度或最低工作距离；先记录目标像素尺寸、深度空洞、曝光、回差和停止后稳定时间。

旧工程取流/扫描/几何证据的迁移条件见[工程交接](ENGINEERING_HANDOFF.md)。开发试采可先检查数据与人工跨视图对应，不必先训练模型；定量比较前必须有可核验的标定/位姿、运行后端与记录程序。使用设备输出深度时，原始左右图不是统一前置条件；所用深度网格、单位、配准与时间语义仍须说明。

附近灌木可用于轴运动、同步、回零、几何去遮挡与去重软件调试；它不能代替茶芽形态分级、自然茶树遮挡分布或茶树泛化实验。正式证据来自真实茶树。

## E01：区域真值与遮挡调查

预先固定三维区域边界、芽梢归属点与标签版本。算法不知道目标数，不允许人工框出隐藏目标。完成同一场景全部预定非破坏性采集或策略运行后，再进行可能拨叶、解遮挡或移除的独立真值复核，保持芽梢与观察阶段的对应证据。记录场景版本、首次干预时间、复核开始时间、可见度、芽簇密度和真值未决项；中途场景变化须换版本，不能继续作为相同初始状态配对。

输出：`regions.csv`、`scene_batches.csv`、`targets.csv` 和代表性图像。首先回答：固定扫描的失败来自小尺寸、深度缺失、完全遮挡、检测器错误、存在确认/删除，还是等级拒绝？这些原因分别记录，等级拒绝不计存在漏检。

## E02：合理的简单扫描基线

比较单视角、固定左右/分层扫描、固定网格扫描。机制层共享检测、关联、确认与删除规则，所有多视角方法允许跨帧融合去重。采用相同初始位置及有限允许视点集，报告同一截止确认清单的发现率与精确率，以及观察事件/实际墙钟曲线。事件预算包含初始与重复观察，每事件帧数/推理次数冻结。

固定网格不能故意选差的角度。通过开发区域确定参数，独立测试区域上冻结参数。如果简单扫描已达实用要求，检查进一步复杂化是否有真实价值。

先用短时稳定的自然茶树多视角回放调查可恢复漏芽，再接入强基线。原始拍摄时间与虚拟运行时间分开，参考视角复拍用于变化质检；动态批次单列。默认重复访问同一位姿返回同一登记图像并收费，不用于验证等待或多帧机制。原始图像和真值均保存，但控制器只获所选观察；不可观测结论只限于该有限允许集合。详细规则见行动前准备第4节。

## E03：闭环选视角与机制消融

先实现一个与任务匹配、资料足够的已发表主动视觉基线，例如基于语义/遮挡信息增益的视点规划；不要只有“单视角 vs 新算法”。T03 记录原算法假设及复现偏差。

拟议方法每次用当前 RGB、深度、稀疏对象/区域记忆选择可达观察位姿，执行后更新。既有芽簇身份/等级不确定性与尚未发现目标的探索需求分别记录；概率云可用，但不用复杂分布作为先验创新主张。

消融针对具体假设：去掉未充分观察区域的探索、仅追求可见面积、仅追求已有候选置信度。主机制比较固定后端；去掉去重仅可作为单列的后端诊断，不能把后端变更的收益归给视角选择。不要为了凑表做无关模块消融。

完整系统比较另列：各方法按相同校准流程确定阈值和确认规则，再冻结到独立验证；改变确认规则会改变决策路径时重跑闭环。只在最终点满足精确率要求不证明全程满足，约束适用预算点须事前定义。

ROI 如作为计算决策，需测板端实际时间：整帧拍摄后裁剪不会减少传感器采集成本；若输入网络尺寸保持不变，单次推理未必更快；整图深度计算可能仍占主要成本。

输出：观察日志、预测记录、预算快照、全部输出条目及匹配、分层错误、同一清单的 `R(B)`/`P(B)` 与耗时。只有收益跨独立区域/日期重复出现，才将其写成结论；同株跨日期的相关性仍须保留。

## E04：采后新暴露目标（后续可选）

人工严格按算法输出移除一个已确认目标，记录移除对象与时间，再运行相机策略。实际移除会改变几何，不用静态回放假装采后状态。

预先定义初始区域及真值核验规则，已移除目标与新暴露目标不重复计数；不能为提前清点而先改变初始遮挡。每次移除建立新场景版本，保留与初始对象的对应证据，另冻结含状态变化的协议。人工步骤和自主观察步骤分开报告；结论限于带人工移除的感知实验。

## 重复与数据划分

自然茶树状态会变化。未采时可重复观察，但记录顺序/风动；有破坏性移除后不能再将同一区域当作相同初始状态。策略比较采用匹配区域、分块随机化或适当交叉顺序，记录理由。

保存区域、植株、日期层级，不能把相邻帧或同株区域当作完全独立样本；划分与不确定性估计保留植株聚类。先导估计失败比例、效应与变异，再确定正式样本量；没有“若干芽必发 Q3”的门槛。训练、阈值校准、策略调参与验证分开。

## 去留门槛

| 观察到的结果 | 行动 |
| --- | --- |
| 无法获得可靠深度或平台位姿 | 先解决可测工作范围；不直接推进概率建图 |
| 数据充分限制收益范围，固定扫描的可恢复增益上限仍不足以值得投入 | 关闭相应 H1/H2 主线或转向实测瓶颈；有限视图参考不冒称全局最优 |
| 多看有效，但主动选视角不优于固定扫描 | 不主张几何决策有效；保留负结果 |
| 好处只来自更宽松准入或更多观察 | 重做同条件对照，不能宣称全面改进 |
| 充分证据表明拟议方法相对已有方法的增量低于预定实用幅度 | 用现有方法，重新审查机制价值；无显著差异不等于等效 |
| 有跨区域可重复的收益与解释 | 固化协议，扩大样本，确定方法贡献后再选刊 |
| 区间宽、真值/场景稳定性未决或约束证据不足 | 标为证据不足，指定最有区分力的补测，不作失败或有效结论 |

最小值得继续投入的收益根据额外计算、运动和硬件成本确定，在独立验证前填入协议冻结表。先导正向信号只支持扩大验证。预算点、加测时间点与资源上限也要事前记录。

## 合作者分工

基础机械/控制：运动与安装设计、回差和成像稳定测量、可达视角、标定、实验可重复性。现代控制：在有数据的前提下建立观察状态、约束和有限时域决策；是否需要 MPC/事件触发由收益决定。视觉：检测与去重基线、等级证据、几何可见性、板端代价。所有角色共用同一真值与指标。
