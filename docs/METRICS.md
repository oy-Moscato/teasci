# 指标与分母

这是研究协议草案。运行前固定区域、类别、匹配规则、阈值与预算，并记录版本。事后不能为了提高数字删掉始终未被看见的芽。

## 目标集合

- `G_all`：预定空间区域中，符合预先定义芽梢单位的全部真值目标。按芽梢独立计数；同一芽的一芽一叶、二叶两种采摘方案不是两个实例。
- `G_eligible`：其中满足指定形态/成熟标准的目标。标签究竟表示在树结构还是预期采下物，必须在 T02 明确。
- 真值由独立人工多角度/逐枝核验，必要时在算法试验后解遮挡或采下检查。不可由检测框并集定义。
- 记录所有目标是否起初可见、是否从允许相机位置可见。不可观测目标计入总体结果并另做分层；如另外报告“可达视角可观测子集”，需同时报告其占全部目标的比例。
- 真值不确定的目标保留 uncertain 和复核原因。给出真值覆盖限制，不把不确定项静默删除。

## 感知主指标

设 `D(B)` 为预算 B 内系统输出并经预先固定规则去重后的目标清单；与真值一一匹配，避免一个预测匹配多芽或重复预测重复加分。

| 指标 | 定义 | 解读 |
| --- | --- | --- |
| 区域累计发现率 `R(B)` | 预算内被正确发现的不同真值芽数 / `|G_all|` | 主要覆盖指标，跨帧累计、按对象去重 |
| 区域残余漏检率 `M(B)` | `1 − R(B)` | 不是机械漏采率 |
| 合格芽发现率 | 正确发现的 `G_eligible` 目标数 / `|G_eligible|` | 是否把适合任务的芽找到；不要求已经正确分级 |
| 准入覆盖率 | 正确接受为合格的真值芽数 / `|G_eligible|` | 同时受发现与分级/拒绝影响 |
| 准入精确率 | 被接受候选中正确匹配且符合等级的唯一目标数 / 全部接受记录数 | 误检、误分级和残留重复不得隐藏 |
| 重复计数率 | 系统去重后仍重复报告同一真值芽的额外记录数 / 输出记录数 | 防止多看几次造成虚假发现收益 |
| 分级混淆矩阵 | 匹配到真值的对象逐等级统计，含拒绝/未知 | 同时报告未发现数，不能只在容易样本上报分类准确率 |
| 首个可靠候选时间 | 从规定初始状态到首次正确准入目标的用时 | 候选充足工作阶段的可选辅助指标 |

上述比例分母为零时写 `NA` 并解释；不能自动填 100%。报告对象微平均和区域宏平均，说明加权方式。不同方法保持初始观察、检测器、可达视角和预算一致。

## 预算与时间

- `K`：观察位姿数量；同一位置连续拍多帧仍需记录实际帧数和推理次数。
- `T_scan`：墙钟时间，从相同初始状态开始，至完成规定预算/停止决策并输出最终候选表。包含平台运动、稳定等待、采集、板端推理、关联/建图和下一视点决策。
- 并行计算与运动时，以墙钟总时间为准，不能把重叠分项直接相加。分别保存分项起止时间。
- 若比较“固定预算内区域发现率”，至少给出 `R(K)` 和/或 `R(T_scan)`；相同 K 但运动距离不同并非相同时间成本。
- 纯视觉实验无 `T_harvest_total`。真实采摘实验再定义整机动作、收集、重试和人工介入时间。

## 实际采摘才使用的指标

区域目标采收率 = 成功采下的合格真值目标数 / 初始 `|G_eligible|`。

采下物规格符合率 = 采下物中符合指定规格的数量 / 全部采下物数量。损伤率独立定义夹痕、撕裂、错误断点等，不能与分级互换。

画面中消失不等于采下；采下不等于成功收集；芽叶完整不等于等级正确。人工代采实验明确人工步骤，不能用作全自主采摘性能结论。

## 失败分类

每个真值目标标记：从未发现 / 发现但身份合并或关联错 / 发现但等级证据不足 / 错误分级 / 正确准入但预算内未处理 / 实际动作失败 / 实际合格完成。静态纯视觉实验只用前五项适用部分。优先根据失败分布决定下一项研究。

## U18：等误检约束的具体操作（协议建议，待预注册）

用累计对象清单精确率下限作为主约束，同时报告每区域伪目标与残留重复数；不把相同单帧置信阈值当成相同误检。各方法在独立校准区域设定阈值与确认规则，然后冻结到测试区域，并检查测试约束是否实际满足。需另报观察预算内首次正确发现数与最终确认清单，避免删除/确认规则掩盖二者差异。

`1−Precision` 是错误发现比例；统计学 FPR 的负例分母在本题不能省略定义。预算后的输出不回填预算内指标。详见 [专项审查第6节](../literature/REGIONAL_DISCOVERY_REVIEW_2026-09-06.md#6-最小但有说服力的比较协议)。
