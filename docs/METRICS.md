# 指标与分母

这是 `pilot-v0.2` 建议协议，待团队复核及现场参数冻结。运行前固定区域、类别、匹配规则、阈值、确认规则与预算，填写[协议冻结表](../experiments/templates/protocol_freeze.md)工作副本。事后不能为了提高数字删掉始终未被看见的芽。

## 目标集合

- `G_all`：预定空间区域中，符合预先定义芽梢单位的全部真值目标。按芽梢独立计数；同一芽的一芽一叶、二叶两种采摘方案不是两个实例。
- `G_eligible`：其中满足指定形态/成熟标准的目标。标签究竟表示在树结构还是预期采下物，必须在 T02 明确。
- 完成该场景全部非破坏性观察后，再由独立人工多角度/逐枝核验，必要时解遮挡或采下检查。保持观察与后验真值身份对照，登记场景和真值版本；不可由检测框并集定义。
- 记录所有目标是否起初可见、是否从有限允许视图可见。不可观测目标计入总体结果并另做分层；另报可观测子集时同时报告其占全部目标的比例。未检查的位置保持未知，未检出不等于不可见。
- 真值不确定的目标保留 uncertain（不确定）和复核原因。报告确定目标统计、未决项的影响范围及覆盖限制，不把不确定项静默删除。所有方法使用相同真值版本。

## 感知主指标

`D(B)` 指预算 `B` 截止时已确认存在、未被删除且已对外可用的清单；`D` 标识输出清单，括号内的 `B` 是该次评价的观察事件或时间预算。清单融合跨帧信息，不是单帧候选并集；确认存在与等级准入分别记录。

主发现率和主精确率必须评价这一份清单。按冻结规则与真值一一匹配，每个真值最多一条输出记正确；残留重复和伪目标仍留在输出分母。允许确认、删除和合并时，截止发现率曲线可能下降，不能取历史最大值或将历史发现率与最新精确率拼接。

| 指标 | 定义 | 解读 |
| --- | --- | --- |
| 截止确认发现率 `R(B)` | 截止清单中正确匹配的不同真值芽数 / `G_all` 中的芽数 | 沿用区域发现主目标，明确为该预算点仍确认的清单 |
| 区域残余漏检率 `M(B)` | `1 − R(B)` | 不是机械漏采率 |
| 对象清单精确率 `P(B)` | 同一截止清单中正确匹配的条目数 / 清单全部条目数 | 主误检约束；伪目标和残留重复不记正确 |
| 合格芽发现率 | 正确发现的 `G_eligible` 目标数 / `G_eligible` 中的芽数 | 是否把适合任务的芽找到；不要求已经正确分级 |
| 准入覆盖率 | 正确接受为合格的真值芽数 / `G_eligible` 中的芽数 | 同时受发现与分级/拒绝影响 |
| 准入精确率 | 截止清单中准入且正确匹配并符合等级的条目数 / 全部准入条目数 | 等级约束，和对象存在的精确率分开 |
| 重复计数率 | 系统去重后仍重复报告同一真值芽的额外记录数 / 输出记录数 | 防止多看几次造成虚假发现收益 |
| 分级混淆矩阵 | 匹配到真值的对象逐等级统计，含拒绝/未知 | 同时报告未发现数，不能只在容易样本上报分类准确率 |
| 首个可靠候选时间 | 从规定初始状态到首次正确准入目标的用时 | 候选充足工作阶段的可选辅助指标 |
| 曾发现数及首次发现时间 | 固定原始候选门槛下、截止前已完成输出的观测级候选中匹配的不同真值及最早时间 | 仅作诊断，不与最终清单精确率配成主结果；事后真值判定不能输入控制器 |

上述 `R`、`M`、`P` 分别标识发现率、残余漏检率和精确率，`B` 为同一预算点，`G_all` 是全部真值芽的集合；残余漏检率是全部真值中未被截止清单正确表示的比例。正确条目除以真值数衡量覆盖，除以输出数衡量可靠性。

表中合格芽发现、准入覆盖、重复计数和分级同样取截止清单，只有明确标记的“曾发现”指标使用历史候选。分母为零时写 `NA`（未定义或不适用）并解释。真值非空、输出为空时发现率为零、精确率未定义，不填100%；真值为空的区域仍保留并报告伪目标数。微平均精确率按全部区域正确条目与全部输出汇总，同时报告区域分布、空输出和伪目标/重复数；不能靠省略未定义区域掩盖失败。不同方法保持初始观察、检测器、可达视角和预算一致。

## 预算与时间

- `K`：观察事件数量，初始观察与重复访问均计入；每事件允许的帧数/推理次数事前固定，不同位姿数另作辅助量。失败事件按冻结规则计费，不临时赠送补拍。
- `T_scan`：墙钟时间，从相同初始状态开始，至完成规定预算/停止决策并输出最终候选表。包含平台运动、稳定等待、采集、板端推理、关联/建图和下一视点决策。
- 并行计算与运动时，以墙钟总时间为准，不能把重叠分项直接相加。分别保存分项起止时间。
- 若比较“固定预算内区域发现率”，至少给出 `R(K)` 和/或 `R(T)`，其中 `T` 是预定墙钟预算，`T_scan` 是实际扫描耗时；相同 K 但运动距离不同并非相同时间成本。
- 纯视觉实验无 `T_harvest_total`。真实采摘实验再定义整机动作、收集、重试和人工介入时间。

时间截止使用当时已对外可用的不可变清单版本。截止前采图、截止后确认的条目不回填；运动可继续完成，但额外耗时与迟到收益另报。事件预算快照在第 K 次事件处理完后保存，不引入第 K+1 次观察，同时保存实际耗时。时间回放须标记成本模型估计，不能把读取数据的耗时当实测扫描时间。

每个预算点保存 `output_snapshots.csv` 元记录（空清单也保存）、`output_items.csv` 全部确认条目、评价侧的 `output_matches.csv` 一一匹配。`state_available_s` 是清单版本在所声明评价时钟中已可用的时间，`recorded_s` 是实际归档经过时间；现场两者从共同运行起点计秒，时间回放则分清模拟时钟与真实归档时钟。归档可稍晚，但不得增加该版本当时没有的内容。真值侧 `outcomes.csv` 无法独立表示伪目标和重复输出，精确率必须从清单侧计算。[字段与关联](../experiments/README.md)

## 实际采摘才使用的指标

区域目标采收率 = 成功采下的合格真值目标数 / 初始 `|G_eligible|`。

采下物规格符合率 = 采下物中符合指定规格的数量 / 全部采下物数量。损伤率独立定义夹痕、撕裂、错误断点等，不能与分级互换。

画面中消失不等于采下；采下不等于成功收集；芽叶完整不等于等级正确。人工代采实验明确人工步骤，不能用作全自主采摘性能结论。

## 失败分类

每个真值目标记录截止状态及原因：从未产生候选 / 有候选但尚未确认存在 / 曾确认但截止已删除 / 身份合并或关联错 / 已确认但等级证据不足 / 错误分级 / 正确准入。等级未知不等于存在漏检，历史发现不等于截止仍在清单。实际动作实验再追加预算内未处理、动作失败、合格完成等状态。优先根据失败分布决定下一项研究；伪目标与残留重复另从输出侧统计。

## U18：等误检约束的具体操作（协议建议，待预注册）

用截止对象清单精确率下限作为主约束，同时报告每区域伪目标与残留重复数。冻结门槛、主预算点及约束适用范围（最终点、全部预定点或全程）；最终点达标不能解释成全程达标。

- 机制层：共享检测、关联、存在状态更新、确认与删除规则，只改视角选择；实际精确率仍可能不同，必须检查共同约束。
- 系统层：各方法按相同校准流程选工作点，冻结至独立验证。确认规则改变反馈路径时须重跑闭环，不能用旧轨迹事后调阈值代替新策略。系统收益不能全部归因于规划。
- 未达到约束的结果保留并标明不满足，不在验证集补调；小样本无法确定时写证据不足。曾发现数另报，不与最终清单精确率拼接。

同株区域与同株跨日期仍可能相关；划分验证集与估计不确定区间时保留植株聚类。重复回放只测算法随机性，不增加独立植株数。

`1−Precision` 是错误发现比例；统计学 FPR 的负例分母在本题不能省略定义。预算后的输出不回填预算内指标。详见 [专项审查第6节](../literature/REGIONAL_DISCOVERY_REVIEW_2026-09-06.md#6-最小但有说服力的比较协议)。
