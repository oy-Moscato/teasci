## 0. 新证据改变了哪些准备工作

旧电脑取流和车载代理实验有可参考程序与记录；不从零重建全部工程。它们尚未确认就是本项目设备，两条链不能混用标定、时钟或性能。1.008°、10.50毫米只保留为旧结果离散/残差统计，9.36%保留为缺原始帧的历史报告值；不作为本题成像、定位或启动门槛。

准备按以下顺序收敛，遇到缺项只阻断依赖该项的阶段：

1. **离线材料先就位**：整理本轮工作协议、实例定义和采集字段；明确拟迁移的代码及差异。本文交付不表示采集程序已改好。
2. **确认本轮设备并完成桌面开发检查**：核对实际型号/安装、冻结当前采集实现，检查数据配对和保存行为；再测可用距离与动作。历史版本找不到不阻止新实现独立验收。
3. **完成一批自然茶树开发试采**：先检验数据链、区域/实例定义与人工对应是否可行，再决定是否扩大。无需先训练模型；人工标注只服务数据审查，不能充当算法发现结果。
4. **进入正式方法比较前冻结协议**：具备适用工作范围、可靠记录/真值、可运行基线、开发与验证隔离，以及已填的预算/约束/去留判据。首次试采不承担论文效果证明。

本轮不重新搜索已缺失的9.36%原始数组，不重复上传完整旧证据包。历史代码只按报告哈希和对应运行目录定点查询一轮；没有定位到便记缺失。若找回新线索再重开。原始左右图仅在重算双目深度或方法明确使用它们时必需；使用设备深度时，优先取得原始保存的彩色图、深度值、有效掩膜规则、单位、输出网格标定、时间语义和位姿证据。完整四关键点、分级网络、机械臂与整机采摘均不作为区域发现试采的统一前提。

## 3. 场景与真值顺序

1. 固定区域、归属点、坐标系、`region_id`（区域编号）、`scene_version`（场景版本）并拍参考图。算法可知区域、标定和动作集，不知真芽数与隐藏芽位置。
2. 完成同一场景全部预定非破坏性采集或在线策略运行，记录时间、顺序、位姿、曝光等参数与参考视角复拍。标注标记不得进入算法输入。
3. 结束观察后再进行可能拨动枝叶、解遮挡或移除的人工核验。保存核验前场景，登记第一次改变场景的时间及真值复核开始时间。
4. 将逐枝核验的芽对应回观察阶段，建立独立目标清单和 `ground_truth_version`（真值版本）。不能以检测框并集定义分母。
5. 中途触碰、移除或发生超出可比性判据的变化时结束旧场景，建立新版本；不能继续声称同场景配对。只修订标注时更新真值版本，对所有方法一致重算。

真值未决项保留原因和证据，报告确定目标与未决项的影响范围；不得静默删除。可观测性依据允许视图中的人工可见证据，不依据检测器是否输出。归属点、匹配容差及邻近目标冲突规则在验证前冻结。

## 4. 回放边界

- 阶段一固定为有限、已采集并校准的位姿集合，每步只开放所选观察。未选图像、全场景重建与真值留在采集/评价侧。
- 用短时近似稳定批次检验空间视角选择；参考视角复拍和变化判据在开发数据上确定。明显变化批次单独标记，不混入稳定批次主比较，也不丢弃原始记录。
- 原始拍摄时间与虚拟运行时间分开保存，避免把风吹产生的显露当作纯视角收益。批次与质检写入 `scene_batches.csv`。
- 默认重复访问同一位姿返回同一条已登记观察，仍消耗一次观察事件。它不产生新时间证据，不能检验等待叶片摆动或多帧抗噪声收益；这些机制须另用时间序列协议。
- “不可观测”只限于当前有限允许视图；未检查的位置保持未知。有限视图并集不证明连续可达空间的全局上界，贪心最佳组合不称严格最优。
- 如做时间回放，运动、稳定、采集和计算成本要有测量来源及模型版本；转移方向和回差有影响时纳入。估计结果单列，最后由在线运行检验。

## 5. 比较、预算与记录验收

机制层固定检测、深度、关联、存在状态更新、确认和删除规则，只改视角选择；仍需检查各方法实测精确率。系统层允许各方法按同一校准流程选工作点，再冻结至独立验证；若确认规则改变反馈路径，须重跑闭环，不能用旧轨迹事后调阈值冒充新在线策略。

冻结主预算轴、主预算点、辅助预算点及误检约束适用范围。只在最终清单达标，不能声称全程达标。观察事件包含初扫与重复访问，每事件帧数/推理次数事前固定；失败、无效图和超时按预定计费规则记账，不临时赠送补拍。

时间截止只计当时已对外可用的清单版本。正在运动的机构可以完成动作；迟到收益不得回填，超时运动成本另报。归档可以稍后落盘，但只能写入当时已保存的不可变快照，不能事后优化输出状态。

下面是未来记录程序需要执行的验收情境，目前不是已通过的软件测试：

| 情境 | 应保存和算出的结果 |
| --- | --- |
| 截止无确认目标 | 有快照元记录，条目为零；真值非空时发现率为零，精确率未定义，不填100% |
| 同芽报告两次，另有一个伪目标 | 三条输出全部保留；最多一条正确、一条重复、一条伪目标；精确率分母为三 |
| 曾正确发现的目标被删除 | 后续快照不再计它，早期记录保持；不能拼接历史发现率与最新精确率 |
| 截止前拍摄、截止后确认 | 截止快照不含迟到目标；保存迟到输出和完成时间作诊断 |
| 最后清单为空，早先有输出 | 显式保存空快照，区分空结果与日志丢失 |
| 参考复拍显示场景变化 | 场景版本与质检原因可追溯；不能继续声称同场景配对 |
| 真值与未选视图存在 | 算法不能读取评价真值或未开放图像，所用证据能追溯到已选观察 |

## 6. 去留与本轮完成边界

先导先估计可恢复漏芽比例、差值、植株/区域间变异和约束可达性，再根据额外成本确定最小值得投入的收益。该门槛写入独立验证前的冻结表，不预填统一百分点或发表成功率。

- 有跨区域可重复信号、约束有希望满足：扩大验证，不据此宣称有效。
- 数据已充分限制收益范围，连可能收益上限也低于值得投入的幅度：停止该机制或采用已有方法。
- 区间宽、真值/稳定性未确定或约束证据不足：标记“证据不足”，注明最有区分力的补测。无显著差异不等于等效。

同株区域和同株跨日期记录可能相关；数据划分和不确定性估计保留植株聚类。重复回放只测算法随机性，不增加独立植株数。
